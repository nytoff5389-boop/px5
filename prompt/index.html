วิธีเชื่อม GitHub กับ AI


ใช้ prompt นี้ให้ AI สร้างเว็บแล้ว push / เปิด PR / merge ขึ้น GitHub ให้เอง ต้องใช้ตัวที่เขียนโค้ดลง repo ได้






push · เปิด PR · merge ได้

Claude Code on the web (claude.ai/code)


    

  1. สร้าง repository บน GitHub ไว้ก่อน (session บนคลาวด์ทำงานกับ repo ที่มีอยู่แล้วเท่านั้น)
    2. 

  2. เข้า claude.ai/code แล้วล็อกอิน ระบบจะให้กด Connect GitHub → อนุญาตบนหน้า GitHub → กลับมาที่ claude.ai/code
    3. 

  3. ติดตั้ง Claude GitHub App ให้บัญชีหรือ organization ที่มี repo แล้วเลือก repo ที่จะให้ใช้ (ถ้าเป็น organization อาจต้องให้ owner อนุมัติ)
    4. 

  4. เลือก repo แล้วเริ่ม session ใหม่ วาง prompt จากไฟล์นี้ได้เลย
    5. 



ถ้าเชื่อมแล้วไม่เห็น repo ให้เช็กว่าแอปติดตั้งแล้วที่ github.com/settings/installations · ถ้าใช้ Claude Code ใน Terminal และมี GitHub CLI อยู่แล้ว เชื่อมได้ด้วยคำสั่ง /web-setup






Codex: push · เปิด PR ได้ChatGPT ปกติ: อ่านอย่างเดียว

Codex (ใน ChatGPT)


    

  1. เปิด Codex ใน ChatGPT แล้วกดเชื่อม GitHub ระบบจะพาไป GitHub ให้อนุมัติแอป ChatGPT Codex Connector
    2. 

  2. เลือก repo ที่อนุญาตให้ใช้ (ต้องติดตั้งแยกให้แต่ละเจ้าของ repo, organization อาจต้องให้แอดมินอนุมัติ)
    3. 

  3. สร้างงานใหม่ เลือก repo แล้ววาง prompt
    4. 

  4. Codex ทำงานใน sandbox เสร็จแล้วตรวจ diff แล้วกด Create PR (บางเวอร์ชันเป็น Push แล้ว Create New PR)
    5. 

  5. การ merge ให้กดใน GitHub หรือสั่งต่อได้ตามสิทธิ์ที่มี
    6. 



GitHub app ใน ChatGPT แชตปกติ (Connectors) ใช้อ่าน/ค้นโค้ดเท่านั้น แก้โค้ดหรือ push ต้องใช้ Codex






Jules: push · เปิด PR ได้แอป Gemini: นำเข้าโค้ดอ่านอย่างเดียว

Jules (โค้ดดิ้งเอเจนต์ของ Google)


    

  1. เข้า jules.google.com ล็อกอินด้วยบัญชี Google
    2. 

  2. กด Connect to GitHub account ทำตามขั้นตอนล็อกอิน แล้วเลือก repo ทั้งหมดหรือบาง repo
    3. 

  3. เลือก repo วาง prompt แล้วกด Give me a plan → อนุมัติแผน
    4. 

  4. เสร็จแล้วกด Publish PR Jules จะ push branch และเปิด Pull Request ให้ แล้วกด merge ใน GitHub
    5. 



แอป Gemini (gemini.google.com)


    

  1. บนคอมพิวเตอร์ กดปุ่มเพิ่มไฟล์ในช่องพิมพ์ → Import code → ใส่ URL ของ repo หรือ branch
    2. 

  2. repo ส่วนตัวต้องเชื่อมบัญชี GitHub กับบัญชี Google ก่อน (ระบบจะให้เชื่อมเมื่อยังไม่ได้เชื่อม)
    3. 



แอป Gemini นำเข้าโค้ดเป็นภาพนิ่ง ไม่ซิงก์และเขียนกลับ repo ไม่ได้ ได้ 1 repo ต่อแชต (ไม่เกิน 5,000 ไฟล์ / 100 MB) และใช้ได้เฉพาะบนคอมพิวเตอร์ ถ้าต้องการให้ push / PR ให้ใช้ Jules






push · เปิด PR · merge ได้ (ผ่าน git + gh)แอปบนคอมพิวเตอร์ ไม่มีบน iPad

Google Antigravity (IDE ที่มีเอเจนต์ AI ในตัว)


    

  1. ติดตั้ง Antigravity บนคอมพิวเตอร์ (Mac / Windows / Linux) แล้วล็อกอินด้วยบัญชี Google
    2. 

  2. ติดตั้ง Git และ GitHub CLI แล้วเปิด Terminal ใน Antigravity พิมพ์ gh auth login เลือก GitHub.com → HTTPS → ล็อกอินผ่านเบราว์เซอร์ (เช็กได้ด้วย gh auth status)
    3. 

  3. ตอนเปิดแอปเลือก Clone repository หรือพิมพ์ gh repo clone ชื่อบัญชี/ชื่อrepo แล้วเปิดโฟลเดอร์นั้น
    4. 

  4. เปิดแผงเอเจนต์ วาง prompt จากไฟล์นี้ เอเจนต์จะใช้ git กับ gh ทำ commit → push → gh pr create → gh pr merge --merge ให้เอง
    5. 

  5. (ทางเลือก) เพิ่ม GitHub MCP server ในการตั้งค่า MCP ของ Antigravity เพื่อให้เอเจนต์จัดการ issue / PR ได้โดยตรง
    6. 



ถ้าต้องให้เอเจนต์รันคำสั่ง Terminal เองโดยไม่ถามทุกครั้ง ให้ปรับโหมดสิทธิ์การรันคำสั่งในการตั้งค่าเอเจนต์ · ยังไม่มีคู่มือทางการของ Google เรื่องเชื่อม GitHub โดยตรง ขั้นตอนนี้อิงวิธีมาตรฐาน git + GitHub CLI
