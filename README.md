# PX5

แพลตฟอร์มรวมแอพทบทวนบทเรียน หน้าแรกเป็นหน้าเลือกแอพ

- `/` หน้าเลือกแอพ PX5
- `/anatomy/` Anatomy (กายวิภาคศาสตร์ BI112 บทที่ 1–7)
- `/calc/` calc (การคำนวณทางเภสัชกรรม PHT111)
- `/px5/` ธีมกลาง (`theme.css`), ปุ่มกลับหน้าเลือกแอพ (`shell.js`), รูปและไอคอน

แต่ละแอพเป็นไฟล์ build สำเร็จ (`app.js`, `app.css`) แล้วโหลด `../px5/theme.css` ทับเพื่อให้หน้าตาเป็นชุดเดียวกัน
ธีมสว่าง/มืดใช้ร่วมกันทุกแอพผ่าน `localStorage['px5.theme']`
